How rows are matched

Each row is matched to a device by its serial number first, then its asset tag. Serial wins because it is stamped on the device by the manufacturer; asset tags get reused across refresh cycles. A row that matches nothing adds a new device — you will see every one of those in the preview before it happens.

A column your file leaves out is left alone, and so is an empty cell. There is no way to clear a field from a CSV — use the device's own edit page for that, where the intent is unambiguous.
